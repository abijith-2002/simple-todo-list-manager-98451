# Ocean Professional Todo App (React)

A simple and intuitive todo list web app with a modern, minimalist UI. The layout follows a centered container with an input field, a list of todos, and filter controls (All / Active / Completed). The theme uses blue and amber accents with subtle gradients and smooth transitions.

## Features

- Create, edit, delete tasks
- Mark complete/incomplete
- Filter by All / Active / Completed
- Clear completed
- Keyboard friendly (Enter to add/save, Esc to cancel edit)
- LocalStorage persistence
- Ocean Professional theme with smooth transitions

## Getting Started

In the project directory, run:

### `npm start`
Starts the app in development mode at http://localhost:3000

### `npm test`
Runs the test suite.

### `npm run build`
Builds the app for production to the `build` folder.

## Structure

- `src/App.js` — Main app logic and components
- `src/App.css` — Ocean Professional theme styles
- `src/index.js` — App entry point

## Accessibility

- Buttons and inputs include ARIA labels where appropriate
- Keyboard interactions supported for adding and editing tasks

## Notes

This is a standalone frontend app using local state. No backend integration is included.
